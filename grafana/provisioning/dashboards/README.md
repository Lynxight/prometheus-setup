# Grafana dashboards

Provisioned into Grafana on startup (see `dashboard.yml`).

## Some of these are generated — check before editing

A dashboard JSON with a `"__generated_by"` key at the top is **generated by a
script and must not be hand-edited** — hand edits are lost the next time the
generator runs. Edit the named generator in `../../../helpers/` and re-run it
instead.

| Dashboard | Generated? | Source |
|-----------|------------|--------|
| `pool_health_metrics.json` | ✅ generated | `helpers/gen_pool_health_dashboard.py` |
| everything else | hand-authored | edit the JSON directly |

Creating a dashboard from a script? Commit the generator to `helpers/`
(`gen_<name>.py` → `<name>.json`) and have it write `"__generated_by"` as the
first key, so the convention stays discoverable.
